# سدرة

مساحة عربية لإدارة المشاريع الشخصية، مع موقع «ميزانية العائلة».

## التشغيل والنشر

- افتح `index.html` في المتصفح لتجربة سدرة محليًا.
- تُحفظ قائمة مشاريع سدرة في تخزين المتصفح المحلي.
- بيانات ميزانية العائلة تُحفظ محليًا في متصفح المستخدم ولا تُرسل إلى خادم.
- يمكن نشر هذا المجلد عبر GitHub Pages بعد رفعه إلى مستودع GitHub.
