# سدرة

موقع شخصي عربي يجمع المشاريع في مكان واحد. يبدأ بواجهة الترحيب المرفقة، ثم ينتقل إلى لوحة المشاريع.

## محتويات الموقع

- `index.html`: واجهة الترحيب ولوحة المشاريع القابلة للإضافة والتعديل والحذف.
- `sidrah-welcome.png`: صورة واجهة البداية.
- `ميزانيتي.html`: موقع ميزانية العائلة.

## البيانات

تُحفظ قائمة المشاريع وبيانات الميزانية محليًا في متصفح المستخدم، ولا تُرسل إلى خادم.

## النشر

الموقع منشور عبر GitHub Pages من الفرع `main` والمجلد الرئيسي للمستودع.
